# hero-video

Custom **hero** block. Purpose: Top-of-page hero with a looping muted background video over a poster image, a heading, short subtext and one CTA.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: poster picture and a link to the .mp4 video file; Row 2: H1, subheading paragraph, CTA link.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

## Behavior

Background video hero: autoplay, muted, looping mp4 behind a dark overlay with poster fallback; H1, subtext and green pill CTA bottom-left; pause/play toggle bottom-right.

## Authoring notes

Use when the hero media is a video. For a still image hero use hero. Without a video link it renders as an image hero.

# cards-blog-slider

Custom **cards** block. Purpose: Horizontal slider of article cards (image, linked title with arrow, category tag pills).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per article: image | linked title, category tag links.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

## Behavior

White article cards (image top, title with arrow icon, outlined category tag pill) in a horizontal slider (about 4.3 visible) with prev/next arrows and progress bar; swipe/drag.

## Authoring notes

One row per article: image | title (linked heading) and a paragraph of category tag links. The title link makes the whole card clickable; tags stay separately clickable.

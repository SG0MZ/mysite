# cards-social-grid

Custom **cards** block. Purpose: Dense image grid of social media posts with hover details, a post overlay on click and a Load more button.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per post: image | author, handle, date, caption, link.

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

## Behavior

Dense 5-column image-only grid of social posts (author, handle and date revealed on hover; click opens a post overlay); 10 initial items with a centered green Load more button that appends more.

## Authoring notes

One row per post: image | author, handle, date, caption, optional link to the post. Ten posts show at first; Load more reveals ten more. Use cards for regular content cards.

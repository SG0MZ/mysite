# embed-designer

Custom **embed** block. Purpose: Tall full-width embed of a third-party interactive tool (e.g. Hover home designer) with an attribution line below.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: Row 1: embed URL link (optional placeholder picture); Row 2: attribution (logo image, link).

## Supported variations

No variations.

## Universal Editor fields

- Content fields derived from the block's decorate contract.

## Behavior

Tall full-width third-party designer iframe (hover.to, about 736px), lazy loaded, with a small attribution logo link below.

## Authoring notes

Row 1: the embed URL (optionally with a placeholder image, which turns loading into click-to-load). Row 2 (optional): attribution logo/link. Use embed for standard 16:9 video/social embeds.
